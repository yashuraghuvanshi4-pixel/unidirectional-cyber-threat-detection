Flow Volume (PPS) vs Source-IP Shannon Entropy H(X) Sliding Window: 10s

Detector Logic & Formula

Detects SYN floods, UDP reflection, and spoofed-source floods by monitoring sudden drops in Source IP Shannon Entropy:

H(X) = - ∑ p(xi) log2 p(xi)
  • High PPS + Low H(X): Single IP flooding target (Direct Flood).
  • High SYN/ACK Ratio (> 0.65): Uncompleted TCP Handshake anomaly.

Flow Inter-Arrival Time (IAT) Variance & Coefficient of Variation (CV)

Periodicity Analysis

Botnet C2 implants (e.g. Cobalt Strike, AsyncRAT) communicate at fixed intervals, resulting in extremely low Coefficient of Variation:

CV = σ / μ ≤ 0.15 (Automated Regularity)

Normal human browsing exhibits high IAT variance (CV > 0.8), whereas C2 beaconing produces flat, regular pulses.

DNS FQDN Length vs Character Shannon Entropy

DGA & Tunnel Heuristics

Analyzes DNS query strings without active resolver probing:

  • Character Entropy H > 4.2: Pseudo-random algorithm domain generation.
  • N-Gram Transition Anomaly: Unnatural consonant-to-vowel ratios.
  • Record Type Anomaly: Frequent TXT/NULL records carrying encoded payloads.

Model Documentation & Architectural Methodology

Machine Learning & Statistical Models

  • Shannon Information Entropy Engine: Computes real-time entropy of IP address spaces and DNS FQDN query strings over 10-second sliding windows.
  • Inter-Arrival Time (IAT) Coefficient of Variation: Detects botnet command-and-control beaconing using standard deviation over mean IAT (\(CV = \sigma / \mu \le 0.15\)).
  • TLS JA3/JA3S & JA4 Fingerprint Matcher: Maps client/server TLS handshake hashes against known malware signatures (TrickBot, Cobalt Strike, AsyncRAT).
  • Sequence of Packet Lengths & Times (SPLT): Profiles the first 15 packet sizes and inter-packet delays of encrypted flows without payload decryption.
  • Isolation Forest & Multi-Class Decision Trees: Trained on benchmark datasets (CIC-IDS2018, UNSW-NB15, CTU-13) for streaming anomaly scoring.

NTRO Architectural Constraints Verification

  • Read-Only Ingest: Input stream processed strictly in passive mode inside enclave; zero socket transmit calls.
  • No Payload Decryption: Encrypted sessions analyzed using transport headers, TLS ClientHello fingerprints, and packet sizes.
  • Streaming Incremental Processing: Bounded latency (< 2.0 ms per flow), no batch waiting required.
  • Sustained Throughput Target: Benchmark tested up to 50,000+ flows/sec (1.2+ Gbps line rate).
